# ECCSA Website

The new website of the **Ethiopian Chamber of Commerce and Sectoral Associations**, with an admin panel where every page can be edited, in **English and Amharic**.

| Part | Technology |
|---|---|
| Website | **Next.js 16** (React 19) + **TypeScript** |
| Admin panel / CMS | **Payload CMS 3** at `/admin` |
| Database | **PostgreSQL** |
| Design | Custom CSS using the ECCSA logo colours (sky blue, gold sunburst, deep navy) |

---

## What can be edited in the admin (`/admin`)

| Admin section | What it controls |
|---|---|
| **Content → News** | News articles (text, photos, gallery, category, draft/publish). The 6 newest "featured" items appear in the top "Latest" ticker. |
| **Content → Events** | Trade fairs, forums, workshops (upcoming/past split is automatic) |
| **Content → Services** | All services, their icon, category and order. The menu and footer update automatically. |
| **Organization → Board & Management** | People, photos, positions, order |
| **Organization → Member directory** | Regional, city, national chambers and sectoral associations (the counts on the Membership page are calculated from this list) |
| **Organization → Partners** | Partner logos and links |
| **Library → Images / Publications** | Photos and downloadable PDFs |
| **Inbox → Contact messages** | Messages sent from the Contact page form |
| **Inbox → Newsletter subscribers** | Emails collected by the newsletter box |
| **Pages → Home, About, Services, Membership, News, Events, Publications, Contact** | Every heading, text, photo, button, number and section on those pages |
| **Settings → Site settings** | Logo, phone, email, address, office hours, map, social media, footer links |
| **Settings → Admin users** | Staff accounts. *Administrator* = everything; *Editor* = content only |

**Amharic:** use the **Locale** switch (top right of the admin) to choose *አማርኛ* and type the Amharic version of any text. If a field has no Amharic text yet, the English text is shown instead. Visitors switch language with the **አማርኛ / English** button on the website.

## Run on your computer

Requirements: Node.js 22+, pnpm, PostgreSQL 16.

```bash
cp .env.example .env        # then edit DATABASE_URL, PAYLOAD_SECRET, SEED_ADMIN_PASSWORD
pnpm install
pnpm seed                   # loads ECCSA's current content + creates the first admin user
pnpm dev                    # http://localhost:3000  (admin: http://localhost:3000/admin)
```

`pnpm seed:fresh` deletes the website content and loads the starting content again (admin users and inbox are kept).

## Deploy on a server (VPS) with Docker

```bash
cp .env.example .env        # DATABASE_URL must use the host "postgres"
docker compose up -d --build
docker compose run --rm seed   # first time only
```

The site runs on port 3000. Put it behind Nginx/Caddy with HTTPS for `ethiopianchamber.com`. The database (`pgdata`), uploaded images (`media`) and PDFs (`publications`) are stored in Docker volumes, so back them up regularly.

Database tables are created and updated automatically on start-up from `src/migrations`. After you change the content model (files in `src/collections` or `src/globals`), run `pnpm payload migrate:create <name>` and commit the new migration.

## Project structure

```
src/
  app/(frontend)/[lang]/   website pages (en / am)
  app/(payload)/           admin panel (generated by Payload)
  collections/             News, Events, Services, People, Members, Partners, Media, Publications, Inbox, Users
  globals/                 editable page content + site settings
  components/              header, footer, cards, forms, menu…
  i18n/                    English & Amharic interface texts
  seed/                    starting content importer
  migrations/              database migrations
seed/                      starting images, PDFs and news (imported by `pnpm seed`)
```
